ДРУЖИЩЕ — АГЕНТ БЛОКНОТ 0.4.17 — автоматическая проверка команд

1. Распакуйте архив в отдельную папку.
2. Сохраните свои документы и закройте окна Блокнота.
3. Запустите START_FULL_TEST.cmd. При первом запуске нужен Python 3.11
   и может понадобиться интернет для установки pywinauto в локальную .venv.
4. Оставьте мышь и клавиатуру агенту до завершения. Ожидание отдельных
   элементов UIA и повтор отложенных проверок могут занять несколько минут.
5. Пришлите Данные/Журналы/*_Notepad_Report.txt и Данные/Навыки/Notepad_Skill.json.

В command_manifest.py записаны 40 исходных пунктов, 34 предыдущих дополнения и ещё 10 пунктов.
Скрипт находит доступные меню, проверяет поддерживаемые команды на пробных
файлах, проверяет часть горячих клавиш по состоянию редактора и вкладок,
раскрывает доступные панели и подменю Markdown. Результат для каждого пункта
каталога находится в Данные/Навыки/Notepad_Skill.json → command_manifest.
В functions сохраняется результат обхода интерфейса, в том числе найденные
элементы Markdown. Это отдельный список и его размер может отличаться.

verified — проверен результат действия;
panel_verified — проверено открытие интерфейса или зафиксировано наблюдение;
unverified — попытка не подтвердила результат;
not_run — проверка не запускалась. Причина указана в отчёте, если прогон прервался.
Проверка через меню не подтверждает горячую клавишу из списка.
Печать в PDF запускается последней. Задание отправляется только после
проверки выбора Microsoft Print to PDF. При успехе файл Notepad_Test_*.pdf
появится в «Данные/Тесты». Если интерфейс не распознан, проверьте отчёт. Тесты буфера обмена, Rewrite, кодировок,
восстановления сессии и изменения оформления пока занесены в каталог.
Стенд записи текста 30/30 и тест восстановления с Qwen запускаются отдельно.

В полном прогоне сначала выполняется штатная проверка. При сбое агент ищет
проверенный профиль в Данные/Память/Notepad_Probe_Recovery.sqlite3. Если профиля нет,
агент обращается к локальной qwen2.5:14b и даёт ей разрешённые варианты.
Запустите Ollama перед пунктом 3. В отчёте ищите строки QWEN и ПАМЯТЬ.
После успешной повторной проверки профиль сохраняется между запусками.
В Данные/Навыки/Notepad_Skill.json виден источник выбора и результат повторной проверки.
Каталог содержит 84 пункта, часть из них пока без автоматического сценария.

Уточнения к прогону 0.4.6

- «Найти» и «Заменить» ищут элементы Edit по роли и AutomationId, затем
  по порядку однозначно определённых новых полей. Перед вводом проверяется фокус.
- «Сохранить как» ждёт появления полного текста. Сверка пробной копии
  учитывает BOM, единые переносы и пробелы или табуляцию в конце строк.
- Перед «Сохранить всё», «Закрыть окно» и «Выйти» агент убирает только
  опознанные вкладки текущего прогона. Вкладки, восстановленные из прошлой
  сессии Блокнота, считаются чужими. Если они есть, сохрани документы и
  закрой старые вкладки по отдельности перед запуском пункта 3.
- Переключение Markdown проверяется на пробном файле .md, а для переноса
  по словам предусмотрены альтернативные способы чтения состояния UIA.

Новые отчёты получают общий порядковый номер, дату и местное время Windows.
Точное имя печатается в консоли. Пример имени отчёта
1_2026-11-08_17-42-06_Notepad_Clipboard_Report.txt
